# Experiment Tracker

[Live Demo](https://experiment-tracker.netlify.app/)

## 💻 Technology Stack

- **Vue 3**
- **TypeScript**
- **Vite**
- **Pinia**
- **PrimeVue**
- **Tailwind CSS**
- **Chart.js**
- **PapaParse**
- **Husky** , **Prettier** , **ESLint**

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/RuslanaTretiakova/exp-tracker
```

2. Install dependencies:

```bash
npm install
```
